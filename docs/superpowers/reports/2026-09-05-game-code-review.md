# 2026-09-05 游戏代码审查与优化

审查基线：`1665538`，本地 Godot `4.7.1.stable.official.a13da4feb`。本轮检查了战斗循环、敌人/子弹生命周期、伤害事件、会话和商店边界、设置加载及 HUD 更新，并对战斗代码和最终差异做了独立复核。

## 已复现并修复

| 问题 | 原行为与影响 | 修复 |
| --- | --- | --- |
| P2：两类敌人的击退失效 | CHASER/SHOOTER 存储并衰减受击冲量，但移动速度未使用它；静止敌人受到 120px/s 冲量后位移为 0。 | 两个角色的移动合成冲量，保留原衰减和 CHARGER 行为。 |

## 范围与限制

- 原压力测试入口 `tools/run_stress_test.ps1` 指向已不存在的 `tests/performance/combat_stress.tscn`；本轮不把它作为性能通过证据。
- HUD 优化结果是实际通知次数变化，不能据此宣称整体 FPS 提升比例。子弹全量扫描敌人的开销尚未做压力剖析。
- 完整无头测试中的图形专用跳过不等于图形验收。当前改动没有改动美术、布局、武器数值或存档 schema；未进行发布包重打包。
- 小地图若完全没有安全刷怪点，会跳过相应刷怪；本次修复保证有限退出，并不承诺任意尺寸自定义地图都有可玩布局。
- 起始工作区的未跟踪 `.uid`/`.import` 文件保留。本轮修复按用户后续要求提交到本地 `main`，未推送远端；运行时代码及测试保持上述最终验证时的内容。
