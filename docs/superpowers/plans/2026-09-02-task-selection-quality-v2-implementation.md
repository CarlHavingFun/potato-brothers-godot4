# 任务选择品质 v2：最小正确实施说明

## 行为边界

- 内容快照只有一个可启动任务时，显示无焦点、无点击行为的“当前任务”摘要；内部任务下拉隐藏并禁用。
- 草稿任务失效但只剩一个可启动任务时，确定性回退到该任务；零任务仍保持 fail closed。
- 内容快照至少有两个可启动任务时，隐藏摘要并启用内联任务下拉。
- 返回、任务下拉与当前角色入口使用明确的四向焦点邻居；任务提交后焦点留在任务控件，不自动跳到难度。
- 零任务及损坏 wave graph 继续 fail closed；不添加占位任务、锁定任务或发行测试内容。
- 任务详情只保留中性的预览说明，不声明尚未由输入测试证明的按键能力。

## 验证边界

- 单元测试分别覆盖零、单、多任务结构，单任务摘要不可交互，多任务焦点图和选择后的焦点保持。
- 原生 960 集成测试先用发行单任务内容截图，再在独立测试快照中注入第二任务验证弹窗。
- 弹窗浏览必须由真实 `InputEvent` 的方向、确认和取消完成，测试不得调用 `set_focused_item()` 代替导航。
- 不修改发行内容 pack；测试用 `gogobro.test:*` 只存在于测试文件。
