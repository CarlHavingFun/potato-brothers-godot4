# Potato Brothers Phase 1 playtest

This is an internal playtest build. It is not a public or commercial release.

## Included

- 6 characters and 11 four-tier weapon families
- 20 passive items and 64 stat upgrade cards
- 10 waves, 5 difficulties, 7 normal/special enemy families, and MouseDog
- upgrades, reward chests, shop, inventory, combining, selling, victory/death,
  unlocks, settings, Simplified Chinese, and English

## Start

Keep `default_content.pck` beside the Windows/Linux executable. On macOS it is
already stored inside the application bundle. Start a new game, select a
character, weapon, and unlocked difficulty.

## Feedback checkpoint

Please record character, weapon, difficulty, wave, build commit, and the exact
behavior when reporting balance, feel, UI, or progression issues. Phase 2 does
not start until this playtest checkpoint is accepted.
