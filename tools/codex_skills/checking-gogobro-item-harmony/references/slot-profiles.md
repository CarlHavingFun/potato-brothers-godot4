# GOGOBRO slot profiles

This reference is the canonical source for slot-specific harmony constraints. Profiles are selected by appearance slot—`head`, `face`, `torso`, `back`, `wrist`, `feet`, `side_left`, `side_right`, `trinket_left`, or `trinket_right`—rather than by a generic fallback.

The paired rig profile and deterministic checker provide the geometry, occlusion, scale, depth, and flip constraints for each slot.
